# Cursor

Profile for [[Hosts]]. Shared rules stay in [[How this vault works]].

- Run python3 _Scripts/setup cursor in Terminal.
- Setup configures the default user's hooks.json and hooks/brain-reminder.py. Generated wrappers call _Scripts/file-session at the selected installation.
- Complete Cursor Settings → Rules → User Rules manually: paste the marked local-host instruction block from Hosts/Web.md and use your actual Brain path.
- Auto-file: supported stop/sessionEnd hooks. Verify actual event delivery with your installed Cursor version.
- Transcript: the local path supplied by the hook.
- fnsh load cursor restores supported missing files, repairs recognized generated wrappers, and preserves custom hook files.
- Apply matching Preferences rows silently.
