## How scope is decided

The project is found from the working directory name, or from the ticket in the first message, the same way Sessions in [[How this vault works]] finds a project. The company is the `Work/<Company>/` area that project belongs to. Match a row's scope to a project by note title or slug, the same way `fnsh load <host> project <name>` does, so every host reads a row the same way. A company name matches a folder under `Work/`. If you cannot decide the project or company, apply only the `all hosts` rows and the rows for this host. Never guess. A personal project has no company, so a company row does not apply there.

## When two rows clash

My current message beats a stored preference. After that, the row with the narrower scope wins, then the newer date. A project beats a company, because the project sits inside that company. A project beats a host. A host beats `all hosts`. A company beats `all hosts`. A company and a host are not nested; if those two clash, ask. If it is still unclear, ask.

If this note cannot be read, apply no rows. Stay silent. Do not reply with an error. The chat continues.

## Repeated asks

`_Scripts/file-session` counts the same ask across session notes and stores it under `repeats` on the note it files. It does not edit this note or [[Parameters]]. At the start step, read the newest session note's `repeats`. When an ask has `chats` of 3 or more, it is not already a row here or a `key: value` line in [[Parameters]], it is not under Declined, and no session note has `offered` for it, ask once: "You keep asking for <ask>. Save it as a preference or a parameter?" The options are Preference, Parameter, and No.

Suggest one. A style or behavior ask (how to reply, what format to give) is a preference and goes in the table above. A value or setting (a number, a limit, a path, a name) is a parameter and goes in [[Parameters]] as one bare `key: value` line, not a numbered rule. If you cannot tell, ask which.

Nothing is saved without my answer. No adds the ask under Declined. Preference appends one row: Area, Preference in my words, Scope (default `all hosts`), and today's date. Parameter adds one line and changes nothing else. Do not change or delete another row.
