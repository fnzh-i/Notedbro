# Code of conduct

Be kind and specific. Critique the change, not the person. No harassment, insults, or personal attacks, in issues, pull requests, or anywhere else in the project.

Maintainers may edit or remove comments, close issues, and block accounts that break these rules.

To report conduct, open an issue with the "Report" form at https://github.com/fnzh-i/Cerebro/issues/new/choose and choose the conduct type. Private vulnerability reporting is for security problems only, not conduct.
